使用说明与安全提示
  • 此网页需要本地 Node.js 服务，不能单独双击 HTML 使用。
  • 默认地址为 http://127.0.0.1:8767，拒绝公网和跨站请求。仅在自己电脑 / 手机运行，勿部署公共 Token 收集站。
  • 只凭手机号不能获取账号 Token；须完成官方验证。没有验证码时不会尝试登录。
  • 短信每次至少冷却 60 秒、同一号码每小时最多 3 次。发送结果不明时，先查看短信，不自动重试。
  • 重新登录可能影响现有 App 登录状态或旧 Token。不要反复登录；有效期以实际 JWT 为准。
  • 刷新页面会丢弃已获取的 Token；15 分钟后本地会话到期。
  • 复制会将凭据放入系统剪贴板；下载 .env 会生成明文文件。用完请自行清除剪贴板或删除文件。

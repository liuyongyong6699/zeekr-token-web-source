## 现在这台 Minis 手机

本次已安装依赖并启动网页，点击：

[打开本机网页](http://127.0.0.1:8767)

仅在运行本服务的设备上有效；应用被系统停止后网页不可用。若服务停止，在 Minis 中执行：

```sh
cd /var/minis/shared/zeekr-token-web
npm start
```

如果自己将源码放在其它目录，把 `cd` 路径改成该目录。无需把手机号、验证码、Token 发给聊天助手。

## 在电脑 / Linux 部署

要求 **Node.js 18+、npm、Chromium / Chrome**。推荐在自己的电脑运行，再把结果复制到青龙。纯 HTML 不能直接调用官方接口：有跨域、风控 SDK 和请求签名要求，因此源码包含 Node.js 后台和临时浏览器。

1. 解压源码包，进入 `zeekr-token-web` 目录。
2. 安装 npm 依赖和浏览器：

```sh
npm ci
npm run browser:install
npm start
```

3. 在**这台机器自己的浏览器**访问 `http://127.0.0.1:8767`。

Debian / Ubuntu 缺少浏览器依赖时，可执行：

```sh
npx playwright-core install --with-deps chromium
```

Alpine / 部分青龙镜像不支持 Playwright 下载的 glibc 浏览器，使用系统包：

```sh
apk add chromium
npm ci
npm start
```

已装 Chrome 但程序未识别：通过 `ZEEKR_CHROMIUM_PATH` 指定可执行文件（不是浏览器目录）。

```sh
ZEEKR_CHROMIUM_PATH=/usr/bin/chromium npm start
```

修改端口：

```sh
ZEEKR_WEB_PORT=8768 npm start
```

服务**固定只监听 127.0.0.1**，验证 Host / Origin / CSRF，不能直接将它放到 VPS 或映射 Docker 端口供公网访问。不要为了方便删除这些检查，避免变成 Token 收集站。若青龙在远程服务器上，推荐先在自己电脑/手机完成登录，复制变量值到青龙，不必把网页部署进青龙。

## 使用

1. 输入自己的 11 位中国大陆手机号，阅读并确认官方条款、可能自动注册及登录影响。
2. 点击「获取图形验证码」。首次加载官网可能需要 10～60 秒。**只有获取图片，不发送短信**。
3. 手动填写图片字符，点击「发送短信验证码」。
4. 收到短信后填写 4～6 位验证码，点击「登录并获取 Token」。
5. 点击「复制变量值」。青龙 → 环境变量：名称 `ZEEKR_TOKEN`，数值粘贴返回的整串 `Bearer …`。
6. 在青龙手动运行先前的签到脚本，确认结果。此页不会自动签到、领奖或修改青龙设置。

网页默认隐藏 Token，可切换显示，也可下载 `.env`。**复制会写入系统剪贴板，下载会生成明文文件**，用完自行清除或删除。

## 验证范围 / 不能保证什么

已验证：
- 官方 PC 官网 `-189` 构建，官方请求封装 / 风控 SDK 加载成功。
- 真实官方图形验证码返回 `code=000000`；PNG / JPEG 字节识别和本地网页显示成功。
- 27 项后端模拟测试及手机网页交互模拟测试通过。

**没有使用真实手机号发短信，也没有拿真实验证码登录，更没有验证返回的官网 JWT 能用于 App 签到。** 登录成功分支是按当前官网请求与返回结构实现，仍需你本人运行一次。

官网 token 与 App token 可能受渠道、设备字段及权限限制；若签到脚本提示设备 ID 缺失、401 / 403，不能视为已适配成功，仍可能需要 App 登录获取的 Authorization。JWT 元信息只是本地解析，**不是对签名的密码学验证**。

上次签到回答所说的“鉴权失败说明签名被接受”不充分：`000009` 最多证明那次鉴权拒绝，不能用来证明登录签名、有效账号或领奖流程已经成功。此工具复用官方请求模块，不拿无效 Token 的返回冒充实测登录成功。

## 安全与隐私

- 本工具服务端不输出手机号 / 图形字符 / 短信验证码 / Token；不生成 HAR、trace 或账号截图，不向通知服务发送凭据。
- Token 只随一条 `Cache-Control: no-store` 响应返回本地网页，不写 URL、Cookie、localStorage、sessionStorage 或源码。
- 本地页面不含统计代码和第三方资源。后台加载极氪官网及**官网原本使用的风控、统计服务**；与普通官网登录相同，不能保证官网本身不产生统计/设备指纹。
- 使用临时浏览器上下文，不导出持久化登录状态。浏览器运行时可产生系统临时文件；正常关闭会清理，因此**不承诺系统层绝对零磁盘痕迹**。默认关闭后端 browser context；重启即丢弃本工具会话。
- 登录成功立即关闭该上下文；「清除本页」和会话到期也清除当前状态。刷新会丢失已返回的 Token。
- 本地会话 15 分钟；同手机号短信至少 60 秒冷却、每小时最多 3 次；登录最多 5 次 / 10 分钟。超时不自动重试发送短信，先看手机是否收到。
- `--no-sandbox` 为 root / Alpine 容器环境兼容使用；浏览器仍不应作为高权限公共服务运行。个人电脑优先用普通用户。
- 重新登录可能使 App 退出、旧 Token 作废；实际有效期以返回 JWT 的 `exp` 为准，不保证固定一年。
- 自动签到属于非官方行为，官方随时可能调整接口和风控。不提供长期可用保证。

## 错误处理

| 提示 | 处理 |
|---|---|
| 需要本地服务 | 不要双击 HTML，在源码目录运行 `npm start`，用 localhost 地址打开 |
| 找不到 Chromium | `npm run browser:install`；Alpine `apk add chromium` |
| 官网或风控加载失败 | 检查服务运行设备是否能访问官网及风险服务；尚未发送短信 |
| 图形验证格式 / 前端变化 | 更新工具，不反复重发短信 |
| 发送结果不明 | 先查看短信；收到后可直接填写登录，60 秒内不要重发 |
| 验证码错误 | 手动核对，禁止循环猜测；次数受限 |
| 会话到期 | 刷新网页；已获取 Token 请提前复制 |
| 登录成功但签到失败 | Token 的 App 渠道兼容性未验证，保留脱敏错误码排查；不要发完整 Token |
